# Workspace Agent Guidelines & Rules

## Free & Open Source Policy for UI & MCP Tools
- **Strict Free-Tier Constraint**: When using MCP tools (such as `21st`, component registries, design generators, or external APIs), **ALWAYS** use only free-tier, open-source, or non-billable features and components.
- **Zero Paid Quota / Credits**: Never perform actions, install components, or query endpoints that consume paid tokens, credits, subscriptions, or paid quotas.
- **Code Ownership & Free Alternatives**: Prioritize free and open-source UI libraries (e.g., shadcn/ui, Tailwind CSS, Lucide icons, open registries) where the user owns and controls the resulting code without recurring licensing or component paywalls.
